# Chamindu Jayakody — Portfolio

A responsive white portfolio website for Chamindu Jayakody,
President of the Media Unit of Sanghabodhi College, Nittambuwa.

## Files

- index.html — page structure and content
- style.css — complete responsive styling and animations
- script.js — navigation, scroll reveal, cursor glow, back-to-top button
- profile.jpg — add your own profile photo here

## Add your profile photo

Put your image in the same folder as `index.html` and rename it:

profile.jpg

Recommended: a clear portrait image in JPG or PNG format.

## Personalize

Open `index.html` and replace:
- `your-email@example.com`
- `@yourusername`
- Facebook placeholder
- YouTube placeholder
- Any experience/skill text you want to change

## Run

Simply open `index.html` in a browser.

For local development, VS Code + Live Server is recommended.
